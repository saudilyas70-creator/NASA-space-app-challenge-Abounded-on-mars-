# Getting Started

## Requirements

- Node.js 20.19+ or 22.12+ and npm.
- VS Code or another code editor.

## Install and start the local site

Open a terminal in the project root, where `package.json` is located, and run:

```sh
npm install
npm run dev
```

Open the local address printed by Vite. Keep the terminal process running while using the site; stop it with `Ctrl+C`.

## Production preview

```sh
npm run build
npm run preview
```

The build output is written to `dist/`. See [[Build and Publish]] for the deployment notes.
