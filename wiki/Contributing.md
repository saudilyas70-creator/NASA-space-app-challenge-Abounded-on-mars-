# Contributing

Keep changes focused and preserve the project’s supplied content, responsive layout, and image attributions.

## Start locally

```sh
npm install
npm run dev
```

Before submitting a change, run `npm run build` from the project root.

## Content and images

- Use project-provided references when editing mission facts; do not add unsupported mission data.
- Keep card, title, and gallery images relevant to their captions.
- For each new or replaced image, update `PHOTO-CREDITS.md` with its available caption, source, image ID, and local path.
- Verify image reuse terms. The MIT license does not cover photos or other third-party media.
- Preserve meaningful alternative text, keyboard access, reduced-motion support, and responsive layouts.

Describe what changed and which page or behavior it affects. Include a screenshot for visible layout changes when practical and report whether the production build succeeded. See `CONTRIBUTING.md` in the source repository for the full guide.
